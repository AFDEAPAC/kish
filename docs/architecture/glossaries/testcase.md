# TestCase Domain Specification

## 1. Overview

TestCase 是本系統的核心資料單位（aggregate root）。

一個 TestCase 代表一次完整的測試資料上傳，包含：

- 測試執行環境（environment snapshot）
- 測試結果（raw text, required）
- 測試腳本（optional）
- 基本識別資訊（id, name, type）

---

## 2. Design Principles

- TestCase 是不可再分的核心資料單位
- TestCase 儲存「事實資料（facts）」，避免混入推論結果
- Raw data 必須完整保留（不可覆蓋）
- Environment snapshot 是 TestCase 的核心組成
- TestCase model 必須保持可擴充性，以支援未來 parser、visualization、analysis 等能力

---

## 3. TestCase Structure

```text
TestCase
├── id
├── name
├── description
├── test_type
├── status
├── tags
├── environment
├── result_artifact
├── script_artifacts[]
├── created_at
└── updated_at
````

---

## 4. Fields

### 4.1 id

* type: string
* required: true
* generated by backend
* globally unique

---

### 4.2 name

* type: string
* required: false
* user-defined or auto-generated

---

### 4.3 description

* type: string
* required: false

---

### 4.4 test_type

* type: string
* required: true

用於指定測試類型，例如：

```text
sglang-benchmark
vllm-benchmark
aiter-benchmark
generic-csv
generic-json
```

---

### 4.5 status

* type: string
* required: true

建議值：

```text
created
uploaded
ready
failed
```

---

### 4.6 tags

* type: string[]
* required: false

---

### 4.7 environment

* type: TestEnvironment
* required: true

詳細結構請參考：

```text
environment.md
```

---

### 4.8 result_artifact

* type: Artifact
* required: true

測試結果（raw text），必須存在。

---

### 4.9 script_artifacts

* type: Artifact[]
* required: false

測試腳本，可選。

---

### 4.10 timestamps

```text
created_at: timestamp
updated_at: timestamp
```

---

## 5. Artifact

```text
Artifact
├── id
├── type
├── filename
├── content_type
├── encoding
├── size_bytes
├── sha256
├── content
├── created_at
```

---

### 5.1 type

```text
test_result
test_script
```

---

### 5.2 content

* type: string
* UTF-8 text only

---

## 6. Constraints

* TestCase 必須包含：

  * environment
  * result_artifact

* script_artifacts 可為空

* 所有 artifact 必須為 pure text（UTF-8）

* 建議大小限制：

```text
test_result <= 5MB
test_script <= 1MB
environment_snapshot <= 5MB
```

---

## 7. Deferred Capabilities

以下能力不在目前 milestone 範圍內，但 TestCase model 應保留擴充性以支援未來整合：

* parser
* parsed metrics
* visualization
* comparison logic
* agent analysis
* campaign grouping
